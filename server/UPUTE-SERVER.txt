=====================================================================
  OSRP | Osijek Roleplay - SERVER PAKET (v1.0.45)
=====================================================================

U paketu:
  fivem-resources\      svih 7 OSRP resursa (osrp_loading, osrp_core, osrp_framework,
                        osrp_accounts, osrp_map, osrp_osijek_map = KARTA Osijeka,
                        osrp_osijek = SKRIPTE grada)
  server\               skripte za instalaciju i pokretanje servera (Windows + Linux)
  server.cfg.example    gotov server.cfg s postavkama (samo upiši svoj ključ)
  UPUTE-SERVER.txt      ove upute


---------------------------------------------------------------------
 NAČIN 1 - AUTOMATSKI (Windows, preporučeno)
---------------------------------------------------------------------
 1. Raspakiraj cijeli paket u neku mapu, npr. C:\OSRP
 2. Besplatni ključ servera: https://portal.cfx.re  ->  Server Keys  ->  New key
 3. Pokreni  server\setup-server.bat
      - skine službeni FXServer
      - skine osnovne resurse (chat, sessionmanager, hardcap)
      - kopira OSRP skripte u  resources\[osrp]
      - pita te za ključ i napravi server.cfg
 4. Pokreni  server\start-server.bat   (sam se ponovno pali ako se ugasi)
 5. U FiveM-u:  F8  ->  connect localhost:30120

 Da se server pali s Windowsom:  server\install-autostart.bat
 (makni s  server\remove-autostart.bat)


---------------------------------------------------------------------
 NAČIN 2 - RUČNO (imaš već svoj FXServer / hosting)
---------------------------------------------------------------------
 1. Kopiraj sadržaj mape  fivem-resources\  u  resources\[osrp]\  na svom serveru
 2. Otvori  server.cfg.example , kopiraj dio "OSRP settings" i "OSRP" (ensure linije)
    u svoj server.cfg (ili koristi cijeli example kao server.cfg)
 3. Upiši svoj ključ umjesto  PUT_YOUR_LICENSE_KEY_HERE
 4. Restartaj server

 Redoslijed ensure linija je bitan:
     ensure osrp_loading
     ensure osrp_core
     ensure osrp_framework
     ensure osrp_accounts
     ensure osrp_map
     ensure osrp_osijek_map     (karta - uvijek PRIJE osrp_osijek)
     ensure osrp_osijek


---------------------------------------------------------------------
 NAČIN 3 - LINUX VPS
---------------------------------------------------------------------
   curl -fsSL https://raw.githubusercontent.com/jakov543/Osrp/main/server/linux/install-osrp.sh | sudo bash
 Skripta te pita za ključ i postavi server kao servis.


---------------------------------------------------------------------
 POSTAVKE (CONFIG)
---------------------------------------------------------------------
 A) Najčešće postavke su u server.cfg (nije potrebno dirati skripte):

   setr osrp_traffic_on true     promet uključen (true) / isključen (false)
   setr osrp_traffic 24          broj auta u prometu oko svakog igrača (10-40)
   setr osrp_language hr         jezik NPC-a: hr ili en
   setr osrp_map nui             nui = nacrtana karta (minimapa + F7), blips = stara
   setr osrp_bulet_unlock 2      BULET e-romobil: otključavanje ($)
   setr osrp_bulet_minute 1      BULET e-romobil: cijena po minuti ($)
   setr osrp_bulet_vehicle ime   BULET kao pravo add-on vozilo (romobil mod). Mod stavi u svoj
                                 resurs sa stream/ mapom, ensure ga PRIJE osrp_osijek, i upiši
                                 spawn ime. Prazno ("") = naš BULET model. Samo uz dopuštenje autora moda!
   setr osrp_bulet_livery 0      livery tog vozila (broj)
   setr osrp_start_cash 500      početna gotovina novog lika
   setr osrp_start_bank 2000     početni novac u banci
   setr osrp_respawn 60          sekunde do respawna nakon smrti
   setr osrp_radio_channel 1     kanal radija (pma-voice)
   setr osrp_crashcam true       filmska kamera pri sudaru (true/false)

 B) Sve ostalo je u config datotekama (otvori u Notepad++ / VS Code):

   resources\[osrp]\osrp_osijek\config.lua
       karta, promet (modeli auta, brzina), NPC-i, ljudi na ulicama,
       BULET romobili, policija (livery), zvukovi, namještaj u kućama
   resources\[osrp]\osrp_framework\config.lua
       početni novac, poslovi, plaće, smrt/respawn, uniforme policije,
       STIL odjeća (cijene po komadu), VOLT trgovina (mobitel, radio, ...)

 Nakon promjene config.lua: restart servera ili u konzoli  restart osrp_osijek


---------------------------------------------------------------------
 ADMIN
---------------------------------------------------------------------
 1. Uđi jednom na server - konzola ispiše tvoju "license:" liniju
 2. U server.cfg odkomentiraj i upiši:
      add_principal identifier.license:TVOJ_LICENSE group.admin
 3. Restart


---------------------------------------------------------------------
 TIPKE U IGRI
---------------------------------------------------------------------
 F7         karta Osijeka (GPS, popis mjesta, pretraga)
 F2         moje stvari (mobitel, radio, tablet ...)
 F10        HUD postavke (što se vidi, veličina, km/h ili mph)
 E          razgovor s NPC-om / najam BULET romobila
 F          kraj vožnje romobilom / uzmi parkirano vozilo
 X          spremi mobitel / radio iz ruke


 VAŽNO: NIKAD ne dijeli server.cfg s upisanim ključem (sv_licenseKey) i
        ne stavljaj ga na GitHub ili Discord.


---------------------------------------------------------------------
 KARTA I SKRIPTE ODVOJENO (od v1.0.44)
---------------------------------------------------------------------
 osrp_osijek_map   = samo karta (modeli, teksture, ytyp). ~89 MB.
 osrp_osijek       = samo skripte (promet, NPC, BULET, bicikli, cutscena,
                     minimapa, F7 karta, config.lua). Mala, brzo se mijenja.

 Kad mijenjaš samo skripte/config, zamijeni samo osrp_osijek - karta ostaje.
 Kad dođe nova karta, zamijeni samo osrp_osijek_map.
 Ako si imao staru verziju: obriši staru mapu osrp_osijek\stream (više ne treba).
